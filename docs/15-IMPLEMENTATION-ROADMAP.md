# Implementation Roadmap

Phase 1: Flutter + React admin + FastAPI + MongoDB + auth/RBAC. Phase 2:
registration, OTP/email verification, profile/session. Phase 3: scheme
CRUD/versioning/catalog. Phase 4: KYC, terms, enrollment, installment
generation. Phase 5: Razorpay, signatures, webhooks, reconciliation,
receipts. Phase 6: due dates, reminders, overdue, completion, benefit.
Phase 7: redemption/refund workflows. Phase 8: admin operations,
reports, notifications, support. Phase 9: security, concurrency,
idempotency, performance, testing, deployment and documentation.

Every phase: Plan → Implement → Run → Test → Fix → Retest → Document.
