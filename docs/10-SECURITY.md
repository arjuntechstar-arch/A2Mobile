# Security

HTTPS, password hashing, OTP expiration/rate limiting, login throttling,
JWT/session controls, refresh-token strategy, RBAC, secure mobile token
storage, sensitive-field encryption, secrets management, payment/webhook
signature validation, strict validation, NoSQL injection protection,
security headers, restricted CORS and audit logging.

Never trust client-provided user ID, amount, installment, benefit,
payment success, KYC status, completion or redemption value. Critical
financial operations require idempotency and safe state transitions.
